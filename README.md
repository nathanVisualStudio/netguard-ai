# NetGuard AI

Desktop application that scans a host or a local network, scores the danger with a machine-learning
model, explains how to patch every issue it finds, and exports the result as a PDF report.

> Only scan networks and machines you own or have written permission to test.
> Unauthorised scanning can be illegal. Public IP addresses are refused by default.

## Stack

| Layer | Tech |
| --- | --- |
| Desktop shell | Electron |
| Front end | React + Vite |
| Services | Python 3.10+, FastAPI, asyncio, scikit-learn, ReportLab |

Electron starts the Python service on a random localhost port with a one-time token. The React window
talks to it over HTTP, and the service refuses any request that does not carry the token.

## Run it

Requirements: Node.js 18+ and Python 3.10+.

```bash
cd service
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd ..

npm install
npm start
```

`npm run dev` starts the same app with Vite hot reload. Set `NETGUARD_PYTHON` to use another interpreter.

A command line version is also available:

```bash
cd service
python -m netguard.cli 192.168.1.0/24 --pdf report.pdf
```

## What it does

- Async TCP scanner with banner grabbing, one IP or any range up to a /24
- Service identification for 30+ common ports and version rules with CVE references
- Per-host risk level and 0-100 score from a RandomForest, with confidence and key risk factors
- Fix steps for every finding and a prioritised action list
- PDF report generated by the service

## About the model

There is no public labelled dataset for this exact problem, so the model is trained on synthetic hosts
sampled from the built-in knowledge base and labelled by an expert scoring function with noise
(`service/netguard/risk_model.py`). It produces smooth, calibrated scores from expert rules and does not
discover new attacks. Replacing the synthetic generator with real labelled scans is the natural next step.
